# Dokumentacja

W tym katalogu leżą tylko pliki dla człowieka. Kod jest w `src/`, strona w `web/`, dane w `data/`. To dokumentacja
**statycznej wersji poglądowej** projektu (nie pełnej platformy).

| Gdzie | Co tam jest |
|---|---|
| [`PRZEWODNIK.md`](PRZEWODNIK.md) | ściągawka po całym repozytorium: co jest w tej wersji, czego nie ma, jak to działa |
| [`../data/README.md`](../data/README.md) | słownik danych: każdy plik, jego źródło i częstotliwość odświeżania |
| [`../sql/README.md`](../sql/README.md) | model bazy SQL, widoki analityczne i sposób ich testowania |
| `biblioteka/` | po jednym pliku `.md` na bibliotekę; z nich generator składa kartę Biblioteka |
| `stan-rynku/instrukcja-oceny.md` | instrukcja codziennej oceny rynku pisanej przez Claude w pełnej platformie |
| `obrazy/` | zrzuty ekranu używane w głównym `README.md` |

Zasady pracy asystenta Claude w repozytorium są w `../.claude/CLAUDE.md`.
